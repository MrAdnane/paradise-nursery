# Paradise Nursery

A shopping cart application for an online plant shop, built with React and Redux Toolkit.

## Features

- Landing page with company name, about section, and a "Get Started" button
- Product listing with 3 categories and 6 plants per category
- "Add to Cart" buttons that disable once a plant is added
- Navbar with Home, Plants, and Cart links, and a live cart item count
- Cart page with quantity controls, delete, totals, checkout ("Coming Soon"), and continue shopping

## Run locally

```
npm install
npm run dev
```
